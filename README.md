# HotspotMenu

一个 macOS 菜单栏实验工具：在没有可用网络时，自动连接指定 iPhone 的个人热点。支持开启/关闭自动连接，以及睡眠唤醒、亮屏、解锁后的快速检查。

> 使用 Apple 私有接口，非 Apple 官方产品。连接流程在 macOS 15.7.7 上经过人工验证；自动触发与各类唤醒场景仍需更多实机验证，不保证其他系统版本兼容。

## 功能

- 菜单栏开关，保存自动连接偏好。
- 指定 iPhone 名称，手动发起一次连接。
- 持续断网 15 秒后尝试连接，任务结束后冷却 2 分钟。
- 睡眠唤醒、屏幕亮起、用户会话恢复、解锁，以及启动工具或打开开关时，立即重新检查网络，跳过普通等待与冷却。
- 合并短时间内的唤醒事件，避免重复连接。
- 网络恢复后清理任务；任务超过 65 秒停止等待。
- 本地诊断日志，不记录热点密码。

## 环境要求

- macOS 15 或更新版本；目前仅在 15.7.7 上验证过核心连接路径。
- Xcode 或 Xcode Command Line Tools，用于编译 Swift 和 Objective-C。
- Mac 与 iPhone 在附近，Wi-Fi、蓝牙开启，使用同一 Apple 账户，iPhone 蜂窝网络和个人热点可用。
- 建议先从系统 Wi-Fi 菜单手动连接一次热点：本工具的系统连接命令依赖已保存的连接凭据。

## 构建与启动

```bash
./HotspotMenu/build.sh
open HotspotMenu/HotspotMenu.app
```

首次运行：

1. 点击菜单栏的「热点 ○」。
2. 打开「设置 iPhone 名称…」，填写设备的完整名称。
3. 使用「立即连接 iPhone」测试。
4. 打开「自动连接」。

默认自动连接关闭，不预置任何个人设备名称。不自动安装登录启动项。生成的应用使用本机临时签名，未经过 Apple 公证。

## 自动连接规则

工具使用 `NWPathMonitor` 判断系统是否存在可用网络路径，每 3 秒执行一次维护检查，网络变化也会触发检查。

| 场景 | 行为 |
| --- | --- |
| 普通断网 | 持续 15 秒后尝试，受 2 分钟冷却约束 |
| 唤醒、亮屏、解锁等 | 收到新的网络状态后，无网络则尽快尝试 |
| 已有可用网络路径 | 不自动切换 |
| Mac 的 Wi-Fi 关闭 | 不自动打开 Wi-Fi，也不尝试连接 |
| 任务正在执行 | 不启动第二个任务 |
| 用户手动联网 | 清理任务并更新菜单状态 |
| 关闭自动连接 | 停止后续自动尝试，不主动断开现有热点 |

「立即」表示开始检查与尝试，不保证瞬间联网。Wi-Fi 尚未恢复时，会在后续检查中重新判断。开盖通过系统产生的唤醒/亮屏通知处理，不直接读取合盖传感器；解锁通知依赖系统实现。

**网络路径可用不代表互联网一定可用。** 已连接但宽带断网、网页认证等场景通常不会自动切换到热点。

## 实现

- Swift / AppKit：菜单栏与偏好设置。
- Network：网络路径监听。
- Objective-C / 私有 `Sharing.framework`：发现个人热点设备，请求开启热点。
- `networksetup -setairportnetwork`：发起一次系统连接请求，使用已保存凭据，不在命令行参数中传递密码。
- CoreWLAN：读取 Wi-Fi 电源与 SSID 状态。

连接过程：

```text
发现指定设备 → 请求开启热点 → 单次系统连接请求 → 观察状态 → 结束
```

macOS 可能隐藏 SSID，所以探针输出 `UNCONFIRMED` 不代表连接失败。工具不会因此反复扫描和重连。父进程停止等待也不能保证撤销已交给系统的请求。

## 命令行诊断

```bash
./HotspotProbe/build.sh
./HotspotProbe/hotspot-probe scan-sharing
./HotspotProbe/hotspot-probe connect-sharing '你的 iPhone 名称'
```

`scan-sharing` 只发现设备；`connect-sharing` 可能切换当前 Wi-Fi。

旧 `scan` / `connect` 命令仅保留用于调查 CoreWLAN 私有接口；本机测试返回 `com.apple.wifi.request.error Code=4`，不用于菜单栏的正常连接流程。

菜单中「查看连接日志」打开：

```text
~/Library/Application Support/HotspotMenu/connection.log
```

日志保存在本机，可能包含设备名称，不包含密码。对外分享前请检查内容。当前日志尚未实现自动轮转。

## 测试与限制

构建脚本自动运行策略与任务状态自测，覆盖普通触发、快速触发、禁用、已有网络、忙碌、冷却、网络恢复、进程结束和超时。

```bash
HotspotMenu/HotspotMenu.app/Contents/MacOS/HotspotMenu --self-test
```

人工已验证设备发现、热点开启及系统连接；自动模式曾出现状态停留问题，已补充任务清理与超时，但仍需持续实机验证。没有通过模拟系统事件来声称完成合盖/唤醒端到端测试。

私有接口可能在系统升级后变更。当前版本不适合作为无人值守联网保障，也不提供 App Store 分发支持。
